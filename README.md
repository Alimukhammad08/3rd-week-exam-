
# Catalyst Analytics — AI & Data Solutions Platform

**Catalyst Analytics** — это высокотехнологичный корпоративный сайт для компании, предоставляющей услуги в области анализа данных, искусственного интеллекта и блокчейн-разработки. Проект выполнен в футуристичном темном стиле с использованием 3D-иллюстраций и ориентирован на демонстрацию инновационных IT-решений.

---

##  Особенности проекта

* **Многостраничная архитектура:** Реализованы страницы Home (Главная), Services (Услуги) и Career (Карьера).
* **Футуристичный UI/UX:** Темная тема с неоновыми акцентами, плавными градиентами и качественными 3D-ассетами.
* **Интерактивный раздел FAQ:** Функциональный аккордеон для ответов на часто задаваемые вопросы.
* **Система подбора кадров:** Страница карьеры с фильтрацией вакансий по категориям, опыту и типу занятости.
* **Pixel Perfect Design:** Точная верстка на основе макета с соблюдением всех сеток и отступов.
* **Адаптивность:** Полная поддержка мобильных устройств и планшетов.

##  Технологический стек

* **Frontend:** React / Next.js
* **Стилизация:** Tailwind CSS / CSS Modules
* **Анимации:** Framer Motion (для появления блоков и интерактивности)
* **Иконки и Графика:** Lucide React / Custom 3D Renders
* **Сборка:** Vite / Vercel

##  Структура страниц

1.  **Home:** Приветственный экран (Hero), лог-бар партнеров, краткий обзор услуг и блок FAQ.
2.  **Services:** Детальное описание направлений: Machine Learning, Blockchain Development, Algorithmic Trading и Data Engineering.
3.  **Career:** Информация о корпоративной культуре и список открытых позиций (Web Designer, Project Manager и др.) с формой подачи заявки.
